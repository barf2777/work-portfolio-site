How I work

I take over messy on-prem estates and leave Git history, scrapeable metrics, and runbooks. For live changes: propose the exact command, wait for approval, run only that.

  • Blast radius — phased moves, dual addressing, rollback exports before the flip.
  • Collector check — listening on the host is not the same as Prometheus can scrape.
  • Write it down — daily outcomes, changelogs, reusable troubleshooting notes.
