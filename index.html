How I work

Prep, then cutover

I take over messy on-prem estates and leave Git history, scrapeable metrics, and runbooks. For live changes: propose the exact command, wait for approval, run only that.

  1. Plan the blast radius Phased moves, dual addressing, rollback exports before the flip.
  2. Check from the collector Listening on the host is not the same as Prometheus can scrape.
  3. Write it down Daily outcomes, changelogs, reusable troubleshooting notes.
