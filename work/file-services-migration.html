File services & DFS migration

DFSDFSRfile backupbrownfield cutover

Scale shared namespaces serving mapped drives across departments · multi-terabyte share data · migration run without a maintenance window users would notice

Situation

Aging file servers and DFS namespaces needed migration while users kept working from mapped drives.

Task

Plan DFS/file moves, understand DFSR foot-guns, and pair file data with the right backup product.

Approach

  1. Separate namespace Offline from “replication stopped.”
  2. Inventory share consumers — apps hardcoding UNC/IP break silently.
  3. Choose file-level backup for share data; don’t pretend PBS covers Excel locks.
  4. Validate access after DNS/IP moves (secure channel + share ACL symptoms look alike).

Result

  • Migration playbook aware of DFSR semantics and vendor UNC hardcodes.
  • Clear backup role split for share data vs VMs.
