Case study

Wazuh for endpoint / DNS visibility

WazuhGPO agent rolloutWindows DNS logsAD-aware deploy

Scale domain-joined Windows estate across a multi-building campus · agents pushed via Group Policy rather than hand installs · manager running as a guest on the on-prem cluster

Situation

AV consoles alone left gaps in host visibility. Windows DNS debug logging was too noisy to use raw.

Task

Deploy Wazuh on-prem, distribute agents via Active Directory mechanisms, and make DNS debug logs actionable.

Approach

  1. Stand up the stack on the hypervisor platform with AD integration in mind.
  2. Roll agents with GPO (or equivalent) rather than USB tours.
  3. Build/adjust decoders for Windows DNS debug — parsing is the product.
  4. Keep console/indexer recovery notes when the UI goes dark.

Result

  • Endpoint log path beyond AV; specific craft on a painful Microsoft log source.
  • Documented recovery when dashboard/indexer misbehaves.

Interview soundbites

“Agent install is easy; decoder quality is the job.”
“If DNS debug isn’t parsed, it’s just disk filler.”
